# Question-time
A simple countdown timer for presentations. Keeping to time allows time for questions!

## Usage
Open `index.html` in a browser
- Initialize the countdown timer by scrolling it up or down.
- Scroll the small digits in the bottom right corner to set a warning at a the specified number of minutes. In addition, another warking is given 1 minute to the end and when time runs out.
- click on the timer to start or stop it.
- Switch between dark and light mode by pressing the icon in the top left.
- Go to full-screen mode by pressing 'F' and exit using the same button or by hitting ESCape.

Open `index.html?t=12:30`, `index.html?t=12.5`, or the same with a minus sign, to default to the chosen time.
